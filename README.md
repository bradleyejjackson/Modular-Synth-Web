# Modular Synth Patch School

A browser version of the Patch School lessons from the Modular Synth plugin. Patch modules together, play them with your computer keys or a MIDI keyboard, and work through the lessons, all in the browser.

**Play it:** https://bradleyejjackson.github.io/modular-synth-web/

The whole site is one file, `index.html`. It is generated from the plugin's lessons and module list, so update it by regenerating the page rather than editing it by hand.
