# Modular Synth Patch School

A browser version of the Patch School lessons from the Modular Synth plugin. Patch modules together, play them with your computer keys or a MIDI keyboard, and work through the lessons, all in the browser.

**Play it:** https://bradleyejjackson.github.io/modular-synth-web/

## Browsers

- Works in a recent Chrome, Edge, Firefox or Safari on a computer. Phones and tablets work, but the rack is small.
- Press **Start sound** first: browsers only play sound after a click.
- A USB MIDI keyboard works in Chrome, Edge and Opera once you allow MIDI. Firefox asks you to add a small site permission first. Safari has no Web MIDI, so use the computer keys (A to K play notes, Z and X change octave).
- Your lesson progress is kept in your browser, not online.

## About

The Modular Synth plugin these lessons come from is a VST3 instrument and standalone app for Windows. It isn't published yet.

The whole site is one file, `index.html`. It is generated from the plugin's lessons and module list, so update it by regenerating the page rather than editing it by hand.
